## Часть 1. Участник 1 — магазин (4 мин)

1. **Концепция (30 сек).** «BugBuster Alchemy — алхимическая лавка для IT-шников, цены в сторипоинтах».
   Показать каталог: неон, стеклянные карточки, «колбы» с артефактами, бейджи редкости
   *Legendary / Epic / Rare / Cursed*, горячая клавиша «/» для поиска.
2. **Каталог (1 мин).** Нажать «🧪 Зелья» → 2 товара. Ввести в поиск «уточка» → 1 товар.
   Ввести «флешка» → экран «404: артефакт не найден».
3. **Корзина (1 мин).** Кнопкой «+ В инвентарь» добавить «Амулет деплоя в пятницу» и «Эликсир анти-выгорания» —
   появляются тосты, в шапке счётчик и сумма 650 SP. Открыть выдвижную панель «Инвентарь героя», нажать «+» → пересчёт. Ввести `DEPLOYFRIDAY` → «−20%», итог **520 SP**.
4. **Оформление (30 сек).** «Оформить →» → нажать «Призвать заказ ✨» на пустой форме — поля подсветились красным.
   Заполнить → окно «Заказ призван!», номер `BB-XXXXXX`.
5. **Для тестировщиков (30 сек).** Открыть DevTools → показать атрибуты `data-testid` на кнопках:
   > «Каждый интерактивный элемент имеет `data-testid` — это контракт между разработкой и QA:
   > я могу менять дизайн, а тесты не ломаются.»
6. **Деплой (30 сек).** Показать в футере `build: a1b2c3d` — SHA коммита, который сейчас на проде.
   > «Сайт деплоится сам: пуш в main → GitHub Actions → GitHub Pages.»

**Переход к У2:** «А теперь представим обычную пятницу…»

## 💥 Живое демо: «случайный» баг (запускает У1, 1 мин)

1. Открыть `shop/app.js`, строка с константой:
   ```js
   const CHAOS_MODE = true; // было false
   ```
   > «Мне сказали чуть-чуть поправить промокод. Пятница, вечер, что может пойти не так?»
2. В терминале:
   ```bash
   git commit -am "feat: улучшил промокод DEPLOYFRIDAY 🙃"
   ```
   ```bash
   git push origin main
   ```
3. Вкладка **Actions** → показать, что запустился пайплайн, триггер `push`, автор — У1.
   Передать слово У2 — пока пайплайн идёт, У2 рассказывает про автотесты.

## Часть 2. Участник 2 — автотесты и CI/CD (6 мин, пока идёт пайплайн)

1. **Архитектура (1.5 мин).** IntelliJ IDEA, дерево `autotests`:
   - `build.gradle`: JDK 21 через toolchain, Playwright, JUnit 5, Allure.
     Вкладка Gradle → своя задача **`playwrightInstall`**: «браузер ставится одной кнопкой».
   - **Page Object Model**: `CatalogPage`, `CartModal`, `CheckoutForm` — «тест говорит на языке бизнеса,
     а локаторы спрятаны в Page Objects».
   - Наведи на метод — показать **Javadoc на русском**.
2. **Тест-кейсы (1 мин).** 8 тестов в 3 классах: фильтр/поиск, пересчёт и очистка корзины,
   E2E-покупка с промокодом (Severity **BLOCKER**), негативные — пустая форма и неверный промокод.
   Открыть `CheckoutTest.shouldBuyWithPromoCode`, показать `@Epic/@Feature/@Story/@Severity` и `Allure.step(...)`.
3. **ScreenshotWatcher (1 мин).**
   > «При падении расширение JUnit 5 делает скриншот всей страницы, сохраняет HTML и URL
   > и прикладывает их в Allure. Хитрость: `TestWatcher` вызывается уже после закрытия браузера,
   > поэтому снимок делаем раньше — в `AfterTestExecutionCallback`.»
4. **Локальный прогон (опционально, 1 мин).** Запустить один тест с `-DslowMo=400` в видимом браузере —
   зал видит, как робот сам кликает по магазину.
5. **Пайплайн (1.5 мин).** Открыть `ci-cd-pipeline.yml`:
   - три триггера: `push`, `schedule` (cron 09:00 UTC), `workflow_dispatch`;
   - Job 1 `deploy-shop` → gh-pages; Job 2 `run-autotests` с `needs: deploy-shop`;
   - шаг ожидания `version.txt`: «тестируем именно ту версию, которую только что задеплоили»;
   - Allure с историей → `gh-pages/allure` с `keep_files: true`, «чтобы не стереть магазин»;
   - `jq` читает `summary.json`, `curl` шлёт сообщение в Telegram, токен — в Secrets.

## Возможные вопросы комиссии

| Вопрос | Кто | Короткий ответ |
|---|---|---|
| Почему Playwright, а не Selenium? | У2 | Автоожидания, быстрее, один API для 3 браузеров, встроенные assertions. |
| Зачем `data-testid`? | У1 | Стабильные локаторы, не зависят от вёрстки и текста. |
| Почему тесты после деплоя, а не до? | У2 | Это smoke/регресс прода; следующий шаг — гонять их на PR против локального сервера до мержа. |
| Как не затирается магазин отчётом? | У2 | `keep_files: true` + `destination_dir: allure`. |
| Где хранится токен бота? | У2 | GitHub Secrets, в логах маскируется. |
| Что если Pages ещё не обновился? | У2 | Шаг ждёт, пока `version.txt` совпадёт с SHA коммита. |
